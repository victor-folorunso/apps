Bitnook Concept project

Small games, instantly.

A shelf of tiny games that live on your phone, and a way to hand one to a friend the way you'd pass a photo: AirDrop, Nearby Share, Bluetooth, WhatsApp. No account, no server, no internet.

Recorded from the app: the shelf, Pentiles, Snake and Dinah.

How it works

  • Every game is a single HTML file that runs sealed off in its own sandbox, with no network access and no way to read anything outside itself.
  • Before you add a game, you're told in plain words what it can do (save progress, vibrate, set the screen orientation), and nothing else is possible.
  • Each game is checked against a fingerprint before it runs, so an altered file is refused.
  • Sound is made inside each game, with no audio files, and is routed so that iPhones play it even with the ring switch on silent.
  • The Android build asks for a single permission: vibration.

The games

Snake, Tic Tac Toe, Memory Match, Pentiles (tap the tiles to play the tune), Dinah (three pieces each, make a line through the middle) and Piano.

Status

Bitnook was tested on Google Play in 2026 and shelved before public release. App stores require a reviewed list of every game an app like this can run, which doesn't fit games passed directly between phones.
