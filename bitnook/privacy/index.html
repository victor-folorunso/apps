Bitnook: Privacy Policy

Last updated 8 October 2026

Bitnook is an app made by wonderperk ("we"). This policy explains what the app does with information about you.

The short version: Bitnook collects nothing. There is no account, no server and no analytics — and the Android build ships without the internet permission, so the operating system itself refuses any network request the app could make.

What stays on your phone

Everything, and it never leaves unless you send it:

  • games you add — the file itself, and how many times you have opened it;
  • your name, if you set one in Settings, so the phone you send a game to can show who it came from. It is written inside that file and nowhere else;
  • an error log, if something goes wrong. Nothing is reported automatically; you can read it, delete it, or choose to send it from Settings.

Deleting the app deletes all of it. There is no copy anywhere else.

When something does leave your phone

Only when you tap Send. That hands one file to your phone's own share sheet, and whatever you pick from there — Nearby Share, Bluetooth, a messaging app, email — does the sending. Bitnook is not part of that transfer and cannot see it. Once the file is with that app, that app's privacy policy applies, not ours.

Games you play

Each game runs sealed off from the rest of your phone, with no network access of its own and no way to read anything outside itself — including other games. A game can save its own progress, vibrate and set the screen orientation, and only if it declared that before you added it. You are shown what a game is allowed to do before it runs.

Games other people send you

Bitnook hosts nothing and distributes nothing. A game reaches you because somebody handed you a file, the same way they would hand you a photo. What a particular game contains is between you and the person who sent it; we never see it and have no way to.

Children

Bitnook collects nothing from anyone, children included. Because games are supplied by whoever sends them to you, what a particular game contains is between you and that person.

Permissions

Bitnook requests no runtime permissions. It asks for no camera, microphone, location, contacts or storage access, and the Android build does not hold the internet permission at all.

Changes

If this policy changes, the date above changes with it. Any version of the app that started collecting data would need a new policy and a new Data safety declaration on Google Play, which you would see before updating.
